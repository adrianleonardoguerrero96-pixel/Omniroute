- **fix(cli):** Windows dashboard no longer reports Claude Code as `settings_found_binary_unresolved` when it was installed with `npm install -g` under `%ProgramFiles%\nodejs`. That stock Node MSI path was trusted for security checks but never actually searched, and Electron often inherits a PATH without it, so `where.exe` missed `claude.cmd` even though a normal shell could run it. Detection now looks there (and puts the directory back on the lookup PATH). Separate from the #7831 `.ps1` / known-path fix for #7774.
