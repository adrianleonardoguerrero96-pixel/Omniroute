- **feat(usage):** redeem **GLM Coding Plan Reset Cards** from the Provider Limits UI. z.ai sells cards that clear an exhausted coding-plan window (5-hour or weekly) before it rolls over on its own, but OmniRoute only ever exposed the passive `nextResetTime`, so the card had to be redeemed on z.ai's own dashboard. The banked count now rides along with the quota poll for `glm` / `glm-cn` / `glmt` / `zai` and the existing reset-credit card, picker and confirmation flow — until now Codex-only — drive it through the new `/api/usage/glm-reset-card` route (`GET` lists, `POST` redeems, reusing z.ai's `requestId` as the idempotency key so a retry cannot burn two cards). The extra list request is only issued for keys that actually report a resettable window and is strictly best-effort, so a card-less account or a transient upstream failure still renders its quotas.
